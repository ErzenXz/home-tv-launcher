Install in a few minutes.

Pick your device. You'll need a computer on the same Wi-Fi for the quickest route.

  1. Turn on developer mode

    On the TV open Settings → System → About and press OK on Android TV OS build seven times. Then turn on Developer options → USB debugging (and network debugging if it's listed).

  2. Install Home

    Download the APK, then from the folder it's in run (use your TV's IP address from Settings → Network):

    adb connect 192.168.1.50
adb install -r Home.apk

    No computer? Install the free Downloader app on the TV and enter this site's address followed by /download.

  3. Make it your home screen

    Some TVs ask which home screen to use when you press Home; choose Home → Always. Google's own TVs don't ask, so switch theirs off (you can undo this at any time):

    adb shell cmd role add-role-holder android.app.role.HOME dev.erzen.home 0
adb shell pm disable-user --user 0 com.google.android.tvlauncher
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx
    Undo: get the original home screen back 
    adb shell pm enable com.google.android.tvlauncher
adb shell pm enable com.google.android.apps.tv.launcherx

  1. Allow apps from other sources

    On the Fire TV open Settings → My Fire TV → About and press OK on the device name seven times. Then in Developer options turn on ADB debugging and allow Apps from Unknown Sources.

  2. Install Home

    Install Downloader from the Amazon Appstore, open it and enter this site's address followed by /download. Or from a computer:

    adb connect 192.168.1.50
adb install -r Home.apk

  3. Send the Home button to Home

    Amazon doesn't let you change the home screen directly. Install the free, open-source Home on Fire app and choose Home: the Home button and startup will open it.

Google TV & Android TV

Chromecast with Google TV, Google TV Streamer, onn, Nvidia Shield, Sony, TCL, Philips Android TVs

Fire TV (Fire OS)

Fire TV Stick 4K, 4K Max, Lite and Cube, with the Home on Fire helper app

Fire TV Stick 4K Select

Runs Vega OS, which only installs apps from Amazon's store

Titan OS, Tizen, webOS

Philips/JVC Titan OS, Samsung and LG TVs can't install Android apps. Plug in a Google TV stick instead

Questions

Is it free?

Yes. Home is free and open source, with no ads, accounts or in-app purchases.

Why does the Top Shelf show photos instead of my shows?

Android only lets the TV's built-in home screen read what apps like Netflix recommend. Home shows hand-picked photography with a few sections for each popular app instead. You can switch to soft colours in Settings.

What data does it collect?

None. It reads the list of apps installed on your TV to show them. If you turn on weather, your city is sent to Open-Meteo to look up the temperature.

Can I go back to my old home screen?

Yes. Uninstall Home, or re-enable the original launcher with the undo commands above.

Is this made by Apple?

No. Home is an independent project inspired by the calm of premium TV boxes. It isn't affiliated with or endorsed by Apple, Google or Amazon.
